# Security and confidentiality

This public case study excludes source code, real health profiles, meal logs, body measurements, consultation notes, authentication tokens, API endpoints, media uploads, and user identifiers. Only sanitized product narrative and approved visuals belong here.

Before publishing mobile screenshots, replace names, avatars, dates, calorie values, medical notes, provider contacts, and order details. Do not include device notifications, debug logs, local storage dumps, or production API configuration.
